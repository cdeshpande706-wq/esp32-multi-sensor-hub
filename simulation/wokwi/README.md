# Wokwi Simulation

This Wokwi simulation demonstrates an ESP32 integrating multiple peripherals through different hardware interfaces.

## Simulated Components

- ESP32
- MPU6050 IMU
- HC-SR04 Ultrasonic Sensor
- Servo Motor

## Interfaces Demonstrated

- **I²C** — MPU6050
- **GPIO** — HC-SR04
- **PWM** — Servo

## Wokwi Simulation

https://wokwi.com/projects/473073016114897921

The simulation is used to validate the circuit architecture, sensor communication, and actuator control before physical implementation.
